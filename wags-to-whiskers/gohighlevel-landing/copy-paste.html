Wags to Whiskers landing page for GoHighLevel

Three blocks: CSS, HTML and JS. Paste them in order, then publish. Photos load from the web, so there's nothing to upload.

1

Custom CSS 1-custom-css.css · 15 KB

In your funnel or website, open the landing page's Settings (gear icon) and choose Custom CSS. Paste it in as-is. No <style> tags are needed.

2

Custom HTML 2-custom-html.html · 10 KB

In the page editor, add a full-width section with 0 padding, then a full-width row with 1 column. Drag in a Custom JS/HTML element (Elements > Custom JS/HTML), click Open Code Editor, paste and save.

3

Custom JS 3-custom-js.html · 3 KB

Page Settings > Tracking Code > Footer Code. Paste as-is, script tags included. You can also paste it into a second Custom JS/HTML element below the first.

After pasting

  • SEO: in page Settings > SEO Meta Data, set the title to Pet Grooming in Long Beach, CA | Book an Appointment and use this description: Voted Long Beach's best groomer seven times. Dog & cat grooming at Los Altos, Tue-Sat 8-5. Book your Wags to Whiskers grooming appointment today.
  • Booking form: requests open the visitor's email app addressed to eric@wagsgrooming.com. To capture leads in GoHighLevel, create a workflow with an Inbound Webhook trigger and paste its URL into data-endpoint="" on the <form id="booking-form"> tag in block 2.
  • Footer links point to /services, /about and /faq. Change them in block 2 if your page paths differ.
  • Header: the block has its own header and footer, so hide the funnel's default header and footer on this page if it has them.
