Advanced Imaging: GoHighLevel Copy Blocks

Click Copy, then paste into the GoHighLevel spot named on each block.

Setup order
  1. Create 5 pages in your GoHighLevel website with paths / (Home), /services, /about, /faq, /contact.
  2. Paste block 1 (CSS) and block 2 (footer code) once, in the website's Settings.
  3. On each page: add a full-width section, set section/row/column padding to 0, add a Custom JS/HTML element, and paste that page's block.
  4. Copy each page's SEO title and description (top of each block) into that page's SEO settings.
